Expected Value & Fair Games

Here probability and data finally shake hands: weight every payoff by its chance, add them up, and you get the long-run average — the key to spotting a fair game.

1 Expected value = the long-run average

If you played this game thousands of times, your winnings per game would settle on one number. That number is the expected value. It's not what you get on any single roll — it's the average over the long run (exactly the settling-down you saw with dice and coins).

2 How to compute it: weight by probability

Multiply each payoff by its probability, then add them all up. Every face of a fair die has chance 1/6, so each term is payoff × 1/6 — the last column. Add the column and you have the expected win per roll.

expected value = (payoff₁ × chance₁) + (payoff₂ × chance₂) + …

3 Fair, favorable, or a rip-off?

Compare the expected win to the cost to play. If they're equal the game is fair (net 0). If the expected win is higher, it's in your favor; if lower, the house wins over time — a rip-off. Try setting the cost to make it fair.
