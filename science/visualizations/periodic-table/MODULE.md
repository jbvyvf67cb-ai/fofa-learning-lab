## Lesson 1 — Reading the periodic table *(migrated from the old atomic-structure doc)*
**Goal:** read a cell and understand rows vs. columns.

Each box shows the **symbol**, the **atomic number**, and the **average atomic mass**.
- A **row (period)** ≈ how many electron shells the atom has.
- A **column (group)** = elements that **act alike**, because they have the **same number of
  outer (valence) electrons**.
- Metals are mostly on the left, nonmetals on the right; the **noble gases** (far-right column)
  barely react because their outer shell is already full.

**Key words:** period (row), group (column), valence electron.
**Try it:** Highlight a group and read the shared property; highlight a period.

**Check yourself:**
1. What do elements in the same column share? _A: same valence electrons; similar behavior._
2. What three things does a cell show? _A: symbol, atomic number, average atomic mass._
3. Why are noble gases unreactive? _A: their outer shell is already full._
