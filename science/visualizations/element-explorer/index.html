Protons go up to Z = 1000: elements past 118 have never been made, but every one has a systematic IUPAC placeholder name (e.g. 120 = unbinilium, Ubn), so they show as theoretical. Existence categories use curated natural-isotope data plus an approximate model of nuclear stability — good for learning the concept, not a substitute for a full chart of nuclides. Super-heavy electron structures are theoretical extrapolations.
