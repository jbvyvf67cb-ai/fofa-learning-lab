Connect to Home Assistant

The lab runs entirely in the browser, so it never holds any API key. Instead it sends results to a Home Assistant webhook — the webhook URL is the only secret, and it lives on this device only. Home Assistant records the measurables and, for open-ended work, uses its Claude key to grade and send feedback back.

Not connected

In Home Assistant, create an automation triggered by a Webhook and paste its URL here. The random webhook id keeps it private.

A second webhook, configured in HA to respond with JSON { "score", "max", "feedback" } after Claude grades the response. Leave blank to skip AI grading.

Progress on this device

Every result is also saved locally, so the lab works even when Home Assistant isn't connected.
